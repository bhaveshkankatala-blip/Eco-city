# Design review brief

`GEMINI_PROMPT.md` is a self-contained brief for asking Gemini Pro (or any design reviewer) for a UI/UX critique and a prioritized visual spec. It was written against the **earlier 2D version (v0.1)**. The game has since moved to the 3D renderer (v0.2), so update section 2 ("Technical constraints") and attach current screenshots from `docs/screenshots/` before reusing it.
